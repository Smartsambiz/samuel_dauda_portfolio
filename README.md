# SAMUEL DAUDA PORTFOLIO 

A modern, responsive web application built with **React**. This is a **frontend-only** project focused on UI/UX and client-side logic, meaning it does not require a backend or database to function.

## 🚀 Demo
samuel-dauda-portfolio.vercel.app

## 🛠️ Built With
React.js

** - JavaScript library for building user interfaces.
*   **Vanilla CSS** - Custom styling without external CSS frameworks like Tailwind or Bootstrap.
*   **JavaScript (ES6+)** - Core logic and functionality.

## ✨ Key Features
*   **React Components**: Modular and reusable UI structure.
*   **Frontend Logic**: Handles all data and state management entirely in the browser.
*   **Fully Responsive**: Styled with custom CSS media queries for mobile, tablet, and desktop views.
*   **No Backend Required**: Designed as a standalone client-side application.

## 📦 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the directory**
   ```bash
   cd samuel_dauda_portfolio
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm start
   ```
   The app will open at `http://localhost:2752`.

## 📂 Project Structure
This project follows a standard React folder structure:
*   `/src`: Contains all React components and custom CSS files.
*   `/public`: Static assets and the base HTML file.
*   `package.json`: Lists project dependencies and scripts.
